# Adarsh Dixit — Full-Stack Portfolio

Modern full-stack developer portfolio built with React + TypeScript (frontend), FastAPI (backend), and PostgreSQL (database).

## Features
- Responsive modern portfolio UI
- 6 featured projects
- Projects, skills, experience, education and achievements
- Contact form persisted to PostgreSQL
- REST API + health endpoint
- Docker Compose for frontend/backend/PostgreSQL

## Run with Docker
docker compose up --build

Frontend: http://localhost:5173
API: http://localhost:8000/docs
